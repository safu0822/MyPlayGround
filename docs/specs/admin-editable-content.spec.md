# 管理画面からのコンテンツ編集

運営者が WordPress 管理画面だけで about・アクセス・Q&A を書き換えられるようにする。
本番はお名前.com のファイルマネージャーへの手動アップロードで運用しており、
ローカルと本番で DB が別のため、内容は DB に持たせ、未設定時は PHP の既定値を表示する。

## 第1弾（実装済み）

| 対象 | 保存先 | 管理画面 | 未設定時 |
|---|---|---|---|
| about 見出し・本文・写真・Instagram URL | オプション `hatatate_content` | サイト文章設定 | `inc/content-defaults.php` の既定値 |
| アクセス 見出し・本文・地図画像・マップURL・乗り継ぎ画像・背景2種 | 同上 | サイト文章設定 | 同上 |
| Q&A | CPT `qa`（質問=タイトル、回答=本文、順序=menu_order） | Q&A | 既定の13件 |

- 空欄で保存した項目は既定値に戻る。
- 本文は `hatatate_render_rich_text()`（`wpautop` + `wp_kses_post`）で出力する。
  このため連続した `<br>` は段落に変わる。行間は `#access p+p` と `.qa-answer p+p` の余白で合わせている。
- Q&A は「現在の内容を管理画面に取り込む」を押すまで既定の13件を表示する。
  取り込まずに新しい Q&A を公開すると、公開した項目だけの表示に切り替わる（管理画面に警告を表示）。
- `hatatate_qa_imported` オプションは取り込み済みの印。取り込み後は既定値へ戻らない。

## 第2弾（未着手）

第1弾の本番確認後に実施する。

- スタッフ: CPT `staff`（名前=タイトル、役割・見出し・紹介=メタ、写真=アイキャッチ）。0件なら `team.json` を表示
- 設備: CPT `equipment`。0件なら `equipments.json` を表示
- 設備スライド画像と動画背景の ON/OFF を設定ページへ追加

## 非目標

- デザイン・レイアウトの変更
- 既存 CPT（blog / news / activity / pricelist）の変更
- トップ・アクティビティのスライダー JSON

## ロールバック

テーマファイルを前の版に戻す。DB 側は `hatatate_content` オプションと `qa` 投稿を消せば既定値の表示に戻る。
